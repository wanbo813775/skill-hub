# 集合、并发与控制流

## 集合

- **[强制]** 重写 `equals` 时同时重写 `hashCode`；集合判空使用 `isEmpty()`。
- **[强制]** `Collectors.toMap` 明确处理重复键，并避免不允许的 `null` 值。不把 `subList` 结果强制转换为 `ArrayList`，也不在父列表结构变更后继续使用旧视图。
- **[强制]** 不修改 `Collections.emptyList/singletonList` 等返回的不可变集合；不通过 `keySet/values/entrySet` 视图执行不支持的结构操作。
- **[强制]** 集合转数组使用类型正确的 `toArray`；`addAll` 前确认输入非空；`Arrays.asList` 返回定长视图，不对它执行增删。
- **[强制]** 遵守 PECS：`? extends T` 集合不添加元素，`? super T` 集合不假定读出类型。不使用 raw type 规避泛型检查。
- **[强制]** 不在 foreach 中直接增删当前集合；删除使用 `Iterator.remove`，并发修改使用并发容器或正确的同步策略。
- **[强制]** `Comparator` 满足自反性、对称性和传递性；警惕整数相减实现比较时的溢出。
- **[推荐]** 根据可预估元素数设置初始容量；遍历 Map 键值对使用 `entrySet`；使用 Map 前明确其键/值是否允许 `null`。

## 并发

- **[强制]** 单例对象及其共享方法必须线程安全。线程和线程池使用可定位业务的名称。
- **[强制]** 业务线程由受管理的线程池提供，不随意 `new Thread`。创建 `ThreadPoolExecutor` 时显式评估核心/最大线程数、队列容量、存活时间、线程工厂和拒绝策略；不使用隐藏无界队列或线程数的 `Executors` 快捷工厂。
- **[强制]** 共享日期格式化器必须线程安全；现代 Java 优先使用不可变的 `DateTimeFormatter`。
- **[强制]** `ThreadLocal` 在 `finally` 中执行 `remove()`，尤其是线程池场景，避免数据泄漏和内存泄漏。
- **[强制]** 优先缩小共享范围和锁粒度。多资源加锁保持全局一致顺序。阻塞获取锁后在 `finally` 释放；`tryLock` 只在确认获锁成功后释放。
- **[强制]** 并发更新同一数据时用唯一约束、乐观版本、数据库/分布式锁或其他适合机制防止丢失更新。
- **[强制]** 定时任务不让一个未处理异常终止后续调度。
- **[推荐]** `CountDownLatch` 的 `countDown()` 放在 `finally`；并发随机数使用 `ThreadLocalRandom`；延迟初始化优先使用静态内部类、枚举单例或已验证的 `volatile` 双检锁。
- **[参考]** `volatile` 保证可见性和有序性，不自动保证复合操作原子性。`HashMap` 不用于无同步并发写；`ThreadLocal` 也不能代替共享对象的同步。

## 控制流与通用规则

- **[强制]** `switch` 的每个 `case` 明确终止或标注继续执行，并提供 `default`。外部字符串进入 `switch` 前检查 `null`。
- **[强制]** `if/else/for/while/do` 都使用大括号，即使只有一行。三元表达式要防止自动拆箱、数值提升和 `null` 导致的意外结果。
- **[强制]** 高并发退出条件不仅依赖“恰好等于”某值，考虑跳跃和重试。
- **[推荐]** 使用卫语句减少多层 `if-else`；复杂判断抽取为有语义的布尔方法；不在条件中嵌入赋值或副作用；循环外预计算不变值。
- **[推荐]** 公开接口对数量、大小、类型、格式和业务边界做入参保护，批量操作必须有上限。
- **[强制]** 重复使用的正则表达式预编译。避免 Apache BeanUtils 这类弱类型反射式属性复制，改用显式映射或编译期生成工具。
- **[推荐]** 可增长数据结构设置容量边界，及时删除无用代码和配置。
