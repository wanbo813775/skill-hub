# Java 基础编码规约

本文件用于 Java 命名、常量、格式、面向对象和日期时间相关任务。规则级别沿用手册 1.7.0。

## 命名

- **[强制]** 名称不以 `_` 或 `$` 开头/结尾；不使用中文、拼音与英文混合命名，国际通用专有名称除外。避免歧视性表达。
- **[强制]** 类名使用 `UpperCamelCase`；方法、参数、成员及局部变量使用 `lowerCamelCase`；常量使用大写字母和下划线。`DO/BO/DTO/VO/AO/PO/UID` 等约定缩写可作为类名组成部分。
- **[强制]** 抽象类以 `Abstract` 或 `Base` 开头，异常类以 `Exception` 结尾，测试类以被测类名开头、`Test` 结尾。数组写为 `Type[]`。
- **[强制]** 包名全小写，每段是单一、自然的英文语义，通常使用单数。避免子父类成员、不同代码块局部变量之间同名，不自创难以识别的缩写。
- **[强制]** POJO 布尔属性不使用 `is` 前缀，避免 JavaBean/序列化框架误判属性名。数据库 `is_xxx` 字段在 ORM 映射中显式映射到 `xxx`。
- **[推荐]** 用完整单词组合表达语义；类型名词可放在名称末尾，如 `workQueue`/`nameList`；使用设计模式时在命名中体现 `Factory`/`Proxy`/`Observer` 等意图。
- **[推荐]** 能力型接口可使用 `-able` 形容词命名。Service/DAO 接口的实现类使用 `Impl` 后缀（仅当项目采用该接口/实现模式）。
- **[参考]** 单个对象查询以 `get` 开头，集合查询以 `list` 开头，统计以 `count` 开头，新增使用 `save`/`insert`，删除使用 `remove`/`delete`；但优先与现有领域语言保持一致。

## 常量和取值

- **[强制]** 不在业务代码中散落魔法值；将有语义的值定义为常量、配置或枚举。`long` 字面量使用大写 `L`。
- **[推荐]** 按功能和复用范围管理常量，不创建包罗万象的全局常量类。有限、稳定的取值集合使用枚举表达。

## 代码格式

- **[强制]** 使用 4 个空格缩进，不使用 Tab；文件使用 UTF-8 和 Unix 换行符。保留字 `if/for/while/switch/do` 与左括号之间留空格，二元/三元运算符两侧留空格，逗号后留空格。
- **[强制]** 单行不超过 120 个字符；换行时使用清晰的连续缩进，操作符随后续内容放在新行，方法链的点号与后续调用放在新行。优先遵循项目已配置的格式化器。
- **[推荐]** 单个方法尽量不超过 80 行；不用人工空格对齐赋值号；用空行分隔不同逻辑语义。不为迎合行数指标做无意义拆分。

## 面向对象与数值

- **[强制]** 通过类名访问静态成员；覆写方法使用 `@Override`；已被外部调用的公开方法不随意修改签名；不使用已过时 API。
- **[强制]** 用已知非空对象或 `Objects.equals` 执行等值判断。包装整数使用 `equals`，不使用 `==`。浮点值不做直接精确相等判断。
- **[强制]** 货币金额以最小货币单位的整数存储，或按领域契约使用明确精度的 `BigDecimal`。`BigDecimal` 比较数值用 `compareTo`；不使用 `new BigDecimal(double)`，改用字符串构造或 `BigDecimal.valueOf`。
- **[强制]** DO 属性类型与数据库字段类型相匹配。POJO 和 RPC 契约优先使用包装类型表达“未赋值”，不为 DO/DTO/VO 属性设置隐式业务默认值。
- **[强制]** 序列化类新增属性时不无故修改 `serialVersionUID`。构造方法不包含业务逻辑。POJO 提供可用于排障的 `toString`，但排除密钥和敏感数据；不同时提供同一布尔属性的 `isXxx` 和 `getXxx`。
- **[推荐]** 循环内拼接字符串使用 `StringBuilder`。适当使用 `final`表达不变性，访问权限从严，优先私有化和最小暴露面。

## 日期时间

- **[强制]** 格式化模式中分清日历年 `y`、月 `M`、分钟 `m`、24 小时 `H` 和 12 小时 `h`。不用周序年替代普通日历年。
- **[强制]** 获取时间戳可用 `System.currentTimeMillis()` 或 `Instant`。新代码优先使用 `java.time` API，避免 `java.sql.Date/Time/Timestamp` 和线程不安全的共享 `SimpleDateFormat`。
- **[强制]** 不把一年硬编码为 365 天，不用毫秒常量模拟日历运算。显式考虑闰年、闰秒、时区和夏令时。
